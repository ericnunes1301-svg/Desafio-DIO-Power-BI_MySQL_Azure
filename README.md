Projeto DIO — MySQL e Power BI
Sobre o projeto
Este projeto foi desenvolvido como parte de um desafio da DIO, com o objetivo de praticar a organização e transformação de dados utilizando o Power BI.
Objetivos
•	Importar e organizar os dados.
•	Corrigir tipos de dados e nomes de colunas.
•	Tratar valores nulos e informações inconsistentes.
•	Combinar tabelas de funcionários, departamentos e projetos.
•	Organizar os dados para análise no Power BI.
Ferramentas utilizadas
•	Power BI Desktop
•	Power Query
•	GitHub
Observação
Durante o desenvolvimento, não consegui realizar a conexão com o Azure. Por isso, optei por adaptar o projeto e focar nas etapas de tratamento e transformação dos dados no Power BI.
Aprendizado
O projeto é uma oportunidade para praticar conceitos de tratamento de dados e desenvolver conhecimentos em Business Intelligence.
